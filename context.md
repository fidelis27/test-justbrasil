# Busca Jurídica

## Contexto do desafio

Recebemos a especificação abaixo. Temos aproximadamente 60 minutos para entregar um protótipo funcional.

O objetivo é criar uma aplicação web de pesquisa de informações jurídicas, permitindo buscar por nome, número de processo ou palavra-chave e visualizar os resultados e seus detalhes de forma simples e eficiente.
