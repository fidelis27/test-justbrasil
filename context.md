# Busca Jurídica

## Contexto do desafio

Recebemos a especificação abaixo. Temos aproximadamente 60 minutos para entregar um protótipo funcional.

O objetivo é criar uma aplicação web de pesquisa de informações jurídicas, permitindo buscar por nome, número de processo ou palavra-chave e visualizar os resultados e seus detalhes de forma simples e eficiente.

- [Technical Specification](tec.spec.md)

## Status de aprovação

- Functional Specification: aguardando aprovação.
- Technical Specification: aguardando aprovação.
- Implementação e build: bloqueados até as duas aprovações explícitas.

## Decisões principais

- Frontend: React com TypeScript e Vite.
- Dados: mocks locais determinísticos.
- Rotas: `/` e `/documento/:id`.
- Estilo: CSS próprio, sem biblioteca visual externa.
